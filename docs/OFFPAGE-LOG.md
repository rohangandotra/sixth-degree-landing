# Off-page opportunities log

Report-only tracking for the twice-weekly SEO routine's off-page section.
Nothing here means anything was sent — the routine never creates accounts,
sends pitches, or contacts anyone; it proposes ready-to-send draft text and
a founder sends it (or doesn't) by hand. This file exists so a future run
can check what's already been suggested instead of relying on memory of
past chat reports, which aren't persisted anywhere else.

Log one line per opportunity the moment it's proposed in a report, whether
or not the founder ends up sending it. Never re-suggest a URL/outlet
already listed here.
